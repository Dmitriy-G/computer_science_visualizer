# Tech stack

The project is **Computer Science Visualizer**; its package and IntelliJ module
use `computer_science_visualizer`, which is also the intended checkout directory
name. Data structures are its current feature area.

- Use TypeScript for application code.
- Use React for the UI.
- Use Vite for development and production builds, and npm for dependencies.
- Write React components in `.tsx` files and other application code in `.ts` files.
- Use separate `.css` files for component styles.

The application uses strict TypeScript. React components use the class-based
style defined in [code style](code-style.md).
